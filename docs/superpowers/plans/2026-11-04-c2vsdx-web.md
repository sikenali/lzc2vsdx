# C2VSDX Web 前端重实现 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完整继承 OpenVS Skills 后端，仅用 Vue 3 重写 5 个前端页面并接通真实生成流程。

**Architecture:** Flask 后端原样加载 `backend/openvs` 继承脚本，新增解析器、内存任务与 SSE；Vue 3 SPA 通过 REST/SSE 驱动 5 个页面，结果页用布局坐标渲染 SVG 预览并下载真实 `.vsdx`。

**Tech Stack:** Vue 3、Vite、Vue Router、Flask、pytest、Remix Icon。

**Spec:** `docs/superpowers/specs/2026-11-04-c2vsdx-web-design.md`

## Global Constraints

- 后端脚本、`graphviz-bin`、Visio COM 渲染完全继承，不修改算法。
- `.vsdx` 导出要求 Windows + Visio 2016+。
- 前端设计基准宽度 1440px；颜色/字号/间距以设计稿为准。
- 主红 `#C0392B`，页面底 `#FAF7F2`，描边 `#E5DFD3`，字体 Source Han Sans 栈。
- 不引入 Pinia；状态用组合式函数 + sessionStorage。

## Review Focus

- 后端未安装 Visio 时：任务应失败并给出明确提示，而不是 500 或卡死。
- 空文本/空白图片：接口返回 422，前端显示可读错误。
- 任务取消：SSE 连接关闭，前端回到输入页，不残留轮询。
- 结果页刷新：`/result/:id` 能从 sessionStorage 恢复标题与统计，下载仍可用。
- 超长文本：解析节点数上限 20，进度与预览不崩溃。
